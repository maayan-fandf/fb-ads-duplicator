FB Ads Duplicator

Select ads in the Ads Manager table, then hit Ctrl+Shift+E or use the button below.

Ad name

Click in the ad name field first, then this button. If no field is focused, the date is copied instead — paste it with Ctrl+V.

Shortcuts

Ctrl+Shift+E  — duplicate selected ads + clean up names
Ctrl+Shift+Q  — collapse / expand both side panels
Alt+Shift+D  — insert today's date (yyyy-mm-dd) at cursor

Fallbacks

Strip "- Copy" only: use this if the auto flow stops before renaming. With the duplicated drafts still selected in the table, just click the button — it opens Find and replace itself and strips " - Copy".
